## 📝 Kesimpulan

Berdasarkan hasil pengujian yang telah dilakukan, sebagian besar endpoint pada API SiCure Procurement System telah berjalan dengan baik dan sesuai dengan yang diharapkan. Hal ini dapat dilihat dari keberhasilan proses utama seperti registrasi, login, autentikasi, pengambilan data user, serta fitur CRUD pada Purchase Requisition (PR) yang menghasilkan response dengan status code yang tepat (200 dan 201).

Selain itu, mekanisme keamanan juga sudah berfungsi dengan baik, ditunjukkan dari keberhasilan pengujian autentikasi menggunakan token serta penanganan error seperti **401 Unauthorized** dan **404 Not Found** yang memberikan response sesuai kondisi.

Namun, masih terdapat kendala pada proses update PR (API-09) yang menghasilkan **500 Internal Server Error**. Hal ini kemungkinan disebabkan oleh input data yang tidak sesuai atau adanya masalah pada proses pengolahan data di backend.

Secara keseluruhan, API sudah berjalan dengan cukup baik dan memenuhi sebagian besar kebutuhan fungsional, meskipun masih perlu perbaikan pada beberapa bagian agar sistem dapat berjalan lebih optimal.
